This project creates a random maze with a reward at the end, and then solves it using AI Reinforcement Learning

You can set the height, width, cell value, wall value, reward and random seed of the maze. 
The maze_generator class contains a function to return the maze in a 2D-array, and a function to print it more user-friendly.

The agent, however, takes a maze as input, with its entrance on the first row, solves it through reinforcement learning, and then returns a path

I also added a function to visualize the maze and the math.
